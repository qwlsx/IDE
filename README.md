# Task List

A simple web application for managing study tasks.

## Project goal

The application helps users remember their study tasks. Users can add new tasks, mark them as completed, and delete tasks they no longer need.

## Technologies

- HTML
- CSS
- JavaScript
- Node.js ja Express
- SQLite

## Planned features

1. Add a task.
2. Mark a task as completed.
3. Delete a task.
4. Save tasks in a database.
